# ============================================================================
# Configuration Notes
# ============================================================================
#
# 1. Hostname:
#    - Must match HOSTNAME_LABEL in each machine's .env file
#    - Use descriptive names: azure-cpu-01, windows-rtx3060, etc.
#
# 2. SSH User:
#    - Default for Azure VMs: azureuser
#    - For local machines: your username
#    - Ensure SSH key-based authentication is configured
#
# 3. IP Address:
#    - Azure VMs: Use public IP from deployment output
#    - Local machines: Use local network IP (192.168.x.x)
#    - Can also use hostnames if DNS is configured
#
# 4. Description:
#    - Human-readable description for documentation
#    - Include VM SKU, GPU type, region for clarity
#
# ============================================================================
# SSH Setup
# ============================================================================
#
# Before using this file, ensure SSH key-based authentication works:
#
# 1. Generate SSH key (if needed):
#    ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
#
# 2. Copy public key to remote machines:
#    # For Azure VMs (done automatically during deployment)
#    # No action needed if you configured sshPublicKey in parameters.json
#
#    # For local machines:
#    ssh-copy-id myuser@192.168.1.100
#    ssh-copy-id myuser@192.168.1.101
#
# 3. Test SSH connection:
#    ssh azureuser@20.123.45.67
#    ssh myuser@192.168.1.100
#
# ============================================================================
